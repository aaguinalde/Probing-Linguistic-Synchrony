# Probing-Linguistic-Synchrony

This repository includes the probing semantic synchrony code used in the study Neural Probing for Construct Validation: Evaluating Transformer-Based Measures of Linguistic Synchrony in Educational Dialogue


generate_distances
This code involves the process of generating semantic synchrony measures at each extracted layer 

prediction_test
This code involves the process of calculating the contribution of each layer towards linguistic dimensions

Further resources on extracting synchrony measures are found in https://github.com/aaguinalde/Transformer-Based-Synchrony
